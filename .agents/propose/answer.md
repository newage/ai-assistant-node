в чаті під кожною відповіддю буде 2 маленькі кнопки "палець вгору", "палець вниз" (це реакція користувача на останню відповідь бота).
обирати варіант не обов'язково, але якщо користувач обирає, тоді відправляються данні на новий ендпоінт.
відповідь під якій обрана реакція, запитання на цю відповідь і сама реакція.
ендпоінт POST /answer
request
```json
{"question": "...", "answer": "...", "reaction": "good|bad"}
```
response 201, тоді в чаті кнопку підсвітити (вибрати), не 201 - в чаті нічого не змінюється
зробити таблицю reactions, з полями id, question (string), answer (string), reaction (string), dt_created (auto)
БД Neon на vercel. треба встановити npm install @neondatabase/serverless
Також в цю таблицю писати запитання на які не повернулась відповідь (це робити зразу на бекенді до відправки помилки на фронт).
